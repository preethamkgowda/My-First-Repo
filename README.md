# 🚦 Smart AI Traffic Control System using ESP32

The Smart AI Traffic Control System is an intelligent traffic management project built using the ESP32 DevKit V1. The system automatically controls traffic signals based on real-time vehicle density detected through IR sensors. It also supports Bluetooth-based manual control, emergency vehicle prioritization, and wireless communication through the NRF24L01 module.

This project demonstrates how IoT and embedded systems can be used to improve traffic flow, reduce congestion, and provide faster access for emergency vehicles.
